So after running the command, when I added this code:  import { toPng } from "html-to-image"; the html-to-image was highlighted in red, indicating it doesn't exist, so I stopped the frontend container on Docker and restarted it. The red error didn't disappear, so need to check more.

So this was the error, nothing to worry about: 

Your node_modules lives in a Docker volume. VS Code reads your local folder, so it may not see the new packages. The app can run fine even while VS Code still shows the red line. To check, open the Dashboard in the browser and click Export. If the preview opens, the packages are working and only VS Code’s squiggle is stale.

If you want the squiggle gone, press Ctrl+Shift+P, type TypeScript: Restart TS Server and press Enter. If it persists even after this, it just means VS Code has no local copy of the packages, which is harmless. 

There was a weird UI error where the topbar was shifting when I switched between the pages and the fix was simple

Problem: While a page was loading it had no scrollbar. Once the content grew, a scrollbar appeared and pushed the top bar about 12px to the left.

Solution: scrollbar-gutter: stable on html reserves the scrollbar space from the start, so nothing shifts.
